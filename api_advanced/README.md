# api_advanced

Python scripts that query the Reddit API (https://www.reddit.com).

| File | Description |
| ---- | ----------- |
| 0-subs.py | Return the subscriber count of a subreddit |
| 1-top_ten.py | Print the titles of the first 10 hot posts |
| 2-recurse.py | Recursively return titles of all hot posts |
| 3-count.py | Recursively count keywords in hot post titles |

## Usage

    python3 0-main.py programming
    python3 1-main.py programming
    python3 2-main.py programming
    python3 3-main.py programming 'python java javascript'
