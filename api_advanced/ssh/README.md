# ssh

Scripts and configuration for connecting to a remote server over SSH.

| File | Description |
| ---- | ----------- |
| 0-use_a_private_key | Connect to the server with the private key ~/.ssh/school |
| 1-create_ssh_key_pair | Create a 4096-bit RSA key pair named school |
| 2-ssh_config | SSH client configuration (key auth only, no passwords) |
